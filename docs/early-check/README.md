# 早期実感触（A3.5）の試験用画像

このディレクトリに、A3.5 で使う試験用の画像を置く。
**手順は `docs/early-check-plan.md` を参照すること。**

## 画像そのものはコミットしない

`.gitignore` でこのディレクトリの画像を除外している。
理由は次のとおり。

- 事業者へ送る画像は、**送った時点で事業者の規約が適用される**。
  リポジトリに置く必要がない
- 容量が大きく、履歴に残す意味がない

## 置いてよい画像の条件

**Tripo の無料アカウントで送る画像は、Tripo に権利を渡してよいものに限る。**
利用規約 第5.2.1条により、無料利用者が送った画像（Inputs）と生成物（Outputs）の
権利は Tripo が保持する（`docs/provider-contracts.md` 第1.6.1節）。

- ❌ 生徒の作品
- ❌ 権利を手放したくない作品
- ⭕ 運営・講師が自作した試験用の画像
- ⭕ 権利を運営が持つ画像

あわせて、**個人を特定できる情報（顔・氏名・学校名など）が写り込んでいないこと**を
送信前に確認する。

## 5枚の選び方

題材タグをばらけさせる（同じタグに偏ると判定表の材料にならない）。

- 単体キャラ / 動物 / 雑貨 / 人物 / 風景 / 複数対象 / 細部多め / その他

登録時の分類は **「運営・講師の自作」**、利用同意は **「不要（自作・お手本等）」** でよい。

## 記録

どの画像をどの題材タグで使ったかは、システム側（検証セット）に記録される。
このディレクトリには画像そのものだけを置き、対応表は作らない。
